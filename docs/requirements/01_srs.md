# Software Requirements Specification (SRS)

## Functional Requirements
- **FR-AUTH-01**: Secure Google OAuth 2.0 authentication.
- **FR-MAIL-01**: Asynchronous Gmail message and attachment indexing.
- **FR-AI-01**: Summarization, intent detection, priority scoring, and sentiment analysis.
- **FR-AI-02**: Action item and deadline extraction.
- **FR-DOC-01**: Document text parsing with Tesseract OCR fallback.
- **FR-DOC-02**: Structured parsing for invoices and contracts.
- **FR-RAG-01**: Vector indexing and semantic retrieval via `pgvector`.
- **FR-REPLY-01**: Human-in-the-loop contextual reply drafting.
- **FR-GRAPH-01**: Relational Action Graph timeline rendering.
